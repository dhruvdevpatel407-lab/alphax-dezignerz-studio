# Photos

Drop client photos here with these exact names and they appear automatically.
Until a photo exists, each card shows its own colour gradient instead.

The client's project keeps its photos in `public/assets/images/domestic-tours/` and `public/assets/images/international-tours/`.
Pick one landscape photo per destination from there and save it here under the name below.

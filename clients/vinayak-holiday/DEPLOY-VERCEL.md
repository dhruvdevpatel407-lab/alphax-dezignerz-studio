# Vercel par live kaise karein

## Windows (sabse aasaan)

1. ZIP ko unzip karo. Folder ka naam `demo9962` hi rehne do.
2. Folder ke andar `DEPLOY-VERCEL.bat` par double-click karo.
3. Pehli baar browser mein Vercel login khulega. Login karke wapas aao.
4. Kaam poora hote hi "Production" wala https link dikhega. Wahi live demo hai.

Node.js chahiye. Na ho to https://nodejs.org se LTS install karo.

## Mac ya Linux

Folder mein terminal kholo aur chalao:

    npx vercel@latest --prod --yes

## Bina kisi install ke

https://app.netlify.com/drop par poora folder drag-and-drop karo. Turant link mil jayega.

## Local par dekhna ho to

Folder mein `index.html` par double-click karo. Browser mein website khul jayegi.
